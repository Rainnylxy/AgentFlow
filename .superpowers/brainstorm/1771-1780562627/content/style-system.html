设计 Section 2：风格系统

根据小说文本自动判断风格，映射到对应的漫画视觉参数体系

风格判断流程

文本分析 → 风格分类 → 视觉参数
📖 小说文本 → 🔍 提取特征词
分析的维度
  • 题材标签：仙侠/武侠/玄幻/都市/校园/科幻/悬疑/历史/言情
  • 叙事节奏：快节奏战斗 ↔ 慢节奏对话
  • 文化背景：中国古代/日本/韩国/西方/架空
  • 语言风格：古典文言/现代白话/轻小说口语
  • 情感基调：热血/阴暗/治愈/悲壮/轻松
风格映射规则（可扩展）
武侠/仙侠/玄幻→ 中式古风
轻小说/校园/恋爱→ Manga 日式
都市/职场/现实→ Webtoon 韩式
科幻/悬疑→ 根据节奏自判
历史/古装→ 中式古风

三种风格视觉参数体系

🎌 日式 Manga

色彩黑白为主 + 灰度网点
阅读方向右翻页，从右到左、从上到下
画幅B5/JIS B5，约 1.45:1
特效速度线、集中线、效果字(拟声词)
对话框异形气泡，形状随情绪变化
SD 关键词manga style, black and white, screentone, speed lines, line art

🇰🇷 韩式 Webtoon

色彩全彩色，柔和调色板
阅读方向竖屏滑动，从上到下
画幅竖版 9:16 或 1:1.6~2
特效渐变背景、透明度层次、动效暗示
对话框圆角矩形，简洁干净
SD 关键词webtoon style, full color, soft palette, manhwa, vertical scroll

🏮 中式古风

色彩水墨风/工笔重彩，低饱和雅致色调
阅读方向灵活：条漫竖滑 or 古风册页
画幅条漫 9:16 或 方形册页 1:1
特效水墨渲染、留白意境、笔触质感
对话框竖排文字、卷轴/题跋风格
SD 关键词chinese ink painting style, gufeng, watercolor wash, ancient chinese comic, elegant muted colors

风格参数设计原则

每种风格定义为一个 StyleProfile 对象，包含约 15-20 个可覆盖的参数。Pipeline 各阶段读取对应参数来约束输出：

StyleProfile {
  name, // "manga" | "webtoon" | "gufeng"
  colorMode, // "bw_screentone" | "full_color" | "ink_wash"
  readingDirection,// "rtl_page" | "vertical_scroll" | "flexible"
  aspectRatio, // "16:9" | "9:16" | "4:3" | "1:1"
  sdBasePrompt, // 注入每张图的风格基座 prompt
  speechBubbleStyle,// 对话框渲染参数
  sfxStyle, // 特效字/拟声词风格
  layoutRules, // 排版引擎约束
  ...
}

风格系统是整个管道的"调色盘"——每个阶段的输出都会受 StyleProfile 约束。这个风格参数体系你觉得够不够？还有什么需要补充的风格或参数？
