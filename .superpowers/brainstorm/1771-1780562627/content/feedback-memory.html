设计 Section 4：反馈记忆与自优化系统

系统记住你的每一次修改偏好，让后续生成越来越懂你

三层记忆架构

📁 项目级记忆

当前这本漫画的专属记忆，项目结束后归档

  • 角色外貌修正记录（"苏墨的眼神应该更冷峻"）
  • 场景风格偏好（"暗巷场景光线再暗一些"）
  • 台词润色历史
  • 被拒绝的生图 prompt 及原因
生命周期：项目期间 → 完成后归档为参考

👤 用户级记忆

跨项目的个人审美偏好，持久化保存

  • 镜头偏好（"我喜欢更多特写和大远景对比"）
  • 节奏偏好（"动作场景格数偏多、对话场景偏少"）
  • 色调偏好（"整体色调偏冷/偏暖"）
  • 对话框风格偏好
  • 忌讳清单（"不要鱼眼镜头""不要过度曝光"）
生命周期：永久 → 持续进化

🎨 风格级记忆

针对特定风格（古风/manga/webtoon）的通用优化经验

  • 古风：墨色浓淡、留白比例、竖排文字偏好
  • Manga：网点密度、速度线强度、拟声词风格
  • Webtoon：色彩饱和度、渐变层次、留白间距
  • SD prompt 中哪些关键词效果好/差
生命周期：永久 → 跨项目积累

反馈学习闭环

每一次用户修改 → 系统提取偏好 → 自动注入后续生成
