设计 Section 3：Pipeline 6 阶段详解

每阶段有明确的输入/输出 Schema、用户介入点（🎯）、和可替换策略

① 文本分析 — LLM 驱动

输入
小说章节全文（可能上万字）
输出
{ genre_tags, style: "gufeng", tone: ["苍凉","暗涌"],
  era: "古代架空", pace: "慢热",
  characters_preview: [{name, role, first_appearance_line}] }
🎯 用户介入 确认/修改风格判断、补充世界观设定、标注重要人物
策略 短章(≤3000字)直接全文分析；长章先让 LLM 分段摘要再汇总。可替换为不同分析模型

② 角色设计 — LLM + 生图

输入
分析结果中的人物列表 + 原文外貌描写段落
输出
CharacterSheet[] {
  name, role,
  appearance: {face, hair, build, clothing, accessories},
  reference_image_url, // 定妆照
  sd_trigger_words, // 生图触发词
  personality_notes
}
🎯 用户介入 审核外貌描述 → 生成定妆参考图 → 不满意可重绘 → 确认锁定
策略 首次出现的角色从原文提取外貌；返回角色从 CharacterSheet 复用，只补充新信息。定妆照生成用高质量 prompt + 多张候选

③ 场景拆分 — LLM 驱动

输入
原文 + 分析结果 + 角色列表
输出
Scene[] {
  id, title, summary,
  characters_in_scene, // 从角色库引用
  emotion_arc, // 情绪变化曲线
  key_dialogue,
  suggested_panels: 3-6 // AI 建议格数
}
🎯 用户介入 审查场景列表：合并/拆分/删减场景、调整每场景格数、标注重点场景
策略 按地点/时间/情绪变化切分；一章通常 3-8 个场景，每个场景 3-6 格。支持手动调整

④ 分镜生成 — LLM 驱动（核心阶段）

输入
场景 + 角色定妆信息 + StyleProfile
输出
Panel[] {
  panel_number,
  visual_description, // 中文 + 构图(前/中/背景)
  character_action, // 角色动作表情
  dialogue, // 台词
  camera_angle, // 特写/中景/远景/俯/仰
  mood,
  sd_prompt, // 英文生图 prompt
  character_refs // 引用角色库ID
}
🎯 用户介入 这是交互最密集的阶段：逐格审查画面描述、调镜头角度、改台词、调整 sd_prompt、增删分镜格
策略 逐场景生成（不是全章一次），每场景完成即可审核。相邻格间强制景别/视角变化。sd_prompt 自动注入 StyleProfile 基座 + 角色触发词 + 画幅比例

⑤ 图像生成 — 云端 API

输入
每格 Panel 的 sd_prompt + CharacterSheet 参考图 + StyleProfile
输出
GeneratedImage[] {
  panel_id, image_url/filepath,
  seed, model_used,
  consistency_score // 自动检测与参考图的相似度
}
🎯 用户介入 逐格查看生图结果 → 标记满意的/不满意的 → 为不满意的格子重绘（改 prompt 或换 seed）
策略 首次生成：取每格 1 张候选，用户标记通过/重绘。
角色一致性：每张 prompt 注入角色触发词 + 可选 IP-Adapter 传参考图。
批量策略：用户确认分镜后可一键批量出图（后台队列），也可逐格精细调整后出图。

⑥ 漫画排版 — 渲染引擎

输入
已生成的图片 + 分镜脚本（含台词、镜头信息）+ StyleProfile 排版规则
输出
ComicPage[] {
  page_number,
  panel_layout, // 格在页上的位置/大小
  speech_bubbles: [{position, text, style}],
  sfx_overlays: [{effect_text, position, style}],
  final_image // 单页/单条最终图片
}
🎯 用户介入 预览排版效果 → 调整对话框位置/大小/样式 → 添加或修改特效字 → 确认导出
策略 Manga：格阵排版（PIL/Pillow 合成），支持异形格、出血。
Webtoon/古风条漫：纵向拼接，格间留白。
对话框：根据 StyleProfile 选择气泡样式，自动计算放置位置（优先上方空白区）。
导出格式：PNG/JPG 单页、WebP、或 PDF 合集。

Pipeline 执行流总结

① 分析 ──→ ② 角色设计 ──→ ③ 场景拆分 ──→ ④ 分镜 ──→ ⑤ 生图 ──→ ⑥ 排版
（每个 → 都是一个用户审核门 🎯，可跳过、可回退、可重做）

6 个阶段覆盖了从文字到漫画成品的完整链路。每个阶段之间的 🎯 就是你作为导演的介入点。这个分阶段设计你觉得合理吗？
